# 上线检查清单

> 光伏预测EMS系统生产环境上线前必须逐项确认的检查清单。

## 一、配置检查

### 1.1 电站参数
- [ ] 光伏装机容量（PV_CAPACITY_KW）与实际一致
- [ ] 经纬度（PV_LATITUDE / PV_LONGITUDE）准确
- [ ] 海拔高度（PV_ALTITUDE）准确
- [ ] 组件倾角（PV_PANEL_TILT）与实际安装一致
- [ ] 系统效率（PV_SYSTEM_EFFICIENCY）根据实际设备调整
- [ ] 温度系数（PV_TEMP_COEFFICIENT）与组件规格书一致

### 1.2 预测参数
- [ ] 预测时长（FORECAST_HORIZON_HOURS）满足调度需求（默认4h）
- [ ] 时间步长（FORECAST_TIME_STEP_MINUTES）与调度步长一致（默认15min）
- [ ] 默认模型类型（MODEL_TYPE）已确认

### 1.3 数据库配置
- [ ] InfluxDB地址（INFLUXDB_URL）正确
- [ ] InfluxDB Token（INFLUXDB_TOKEN）已配置且权限足够
- [ ] InfluxDB组织（INFLUXDB_ORG）和Bucket（INFLUXDB_BUCKET）已创建
- [ ] InfluxDB数据保留策略已配置（建议至少保留1年）
- [ ] S3/MinIO地址（S3_ENDPOINT）正确
- [ ] S3访问密钥（S3_ACCESS_KEY / S3_SECRET_KEY）已配置
- [ ] S3 Bucket（S3_BUCKET）已创建

### 1.4 Kafka配置
- [ ] Kafka地址（KAFKA_BOOTSTRAP_SERVERS）正确
- [ ] Kafka Topic已创建：weather_raw、inverter_raw、meter_raw
- [ ] Kafka消费者组（KAFKA_GROUP_ID）已配置
- [ ] Kafka数据保留时间已配置（建议至少7天）

### 1.5 求解器配置
- [ ] 求解器引擎（SOLVER_ENGINE）已确认（pulp/gurobi）
- [ ] 如使用Gurobi，license文件（GUROBI_LICENSE_PATH）已挂载且有效
- [ ] 求解时间上限（GUROBI_TIME_LIMIT）已设置

### 1.6 安全配置
- [ ] API密钥（API_SECRET_KEY）已修改为强随机值
- [ ] 生产环境（ENV=production）已设置
- [ ] CORS允许来源已限制为具体域名（非*）
- [ ] 数据库密码、Token等敏感信息已使用Secret管理（K8s）
- [ ] 日志级别（LOG_LEVEL）已设置为INFO或WARN

## 二、功能检查

### 2.1 数据接入
- [ ] Kafka消费者能正常接收气象站数据
- [ ] Kafka消费者能正常接逆变器数据
- [ ] Kafka消费者能正常接电表数据
- [ ] 数据能正常写入InfluxDB
- [ ] 原始数据能正常归档到S3/MinIO
- [ ] 数据断连时能触发告警

### 2.2 数据处理
- [ ] 数据清洗规则生效（异常值检测、缺失值填充）
- [ ] 多源数据时间戳对齐正常
- [ ] 15分钟重采样正常
- [ ] 特征工程输出正确（气象特征、历史功率特征、日历效应特征）
- [ ] 数据质量报告能正常生成

### 2.3 模型预测
- [ ] 物理模型预测结果合理（白天>0，夜间=0，不超装机容量）
- [ ] XGBoost模型已训练且能正常预测
- [ ] LSTM模型已训练且能正常预测
- [ ] 预测接口响应时间满足要求（<5s）
- [ ] 预测结果能正常写入InfluxDB
- [ ] 预测结果格式符合MPC调度要求

### 2.4 模型评估
- [ ] NMAE计算正确
- [ ] 合格率计算正确
- [ ] 等级评定（S/A/B/C/D）正确
- [ ] 模型对比报告能正常生成
- [ ] 最优模型自动选择逻辑正确

### 2.5 MPC调度优化
- [ ] MPC优化接口能正常调用
- [ ] 优化结果满足功率平衡约束
- [ ] 优化结果满足SOC上下限约束
- [ ] 优化结果满足电网功率约束
- [ ] 储能充放电计划合理（谷充峰放）
- [ ] 求解器不可用时启发式兜底策略生效
- [ ] 优化结果能下发到EMS/SCADA

### 2.6 模型管理
- [ ] 模型列表接口正常
- [ ] 模型训练接口能正常触发（异步）
- [ ] 训练状态查询接口正常
- [ ] 模型切换（activate）接口正常
- [ ] 当前激活模型查询接口正常

### 2.7 监控与运维
- [ ] 健康检查接口正常
- [ ] Prometheus指标接口正常
- [ ] Grafana看板能正常展示数据
- [ ] 预测精度监控（NMAE/合格率趋势）正常
- [ ] 系统资源监控（CPU/内存）正常
- [ ] 定期重训练任务已配置并生效
- [ ] 重训练后模型自动切换逻辑正常
- [ ] 告警规则已配置（服务异常、精度不达标）

## 三、性能检查

### 3.1 接口性能
- [ ] 预测接口P95响应时间 < 3s
- [ ] MPC优化接口P95响应时间 < 10s
- [ ] 健康检查接口响应时间 < 100ms
- [ ] 并发10请求下服务稳定（无错误、无超时）

### 3.2 资源使用
- [ ] 服务启动后内存占用 < 2GB
- [ ] 预测时CPU使用率 < 80%
- [ ] MPC优化时CPU使用率 < 90%
- [ ] 内存无持续增长（无内存泄漏）
- [ ] 磁盘空间充足（模型存储+日志+数据）

### 3.3 数据处理性能
- [ ] 单批次数据清洗耗时 < 10s（10万条）
- [ ] 特征工程耗时 < 30s（10万条）
- [ ] 模型训练耗时合理（XGBoost<5min，LSTM<30min）

## 四、可靠性检查

### 4.1 高可用
- [ ] K8s部署时副本数 ≥ 2
- [ ] HPA自动扩缩容已配置
- [ ] 滚动更新策略已配置（maxUnavailable=0）
- [ ] 服务异常时能自动重启（restartPolicy=Always）
- [ ]  readinessProbe / livenessProbe已配置

### 4.2 数据可靠性
- [ ] InfluxDB数据已配置定期备份
- [ ] 模型文件已备份到S3/对象存储
- [ ] Kafka数据有副本（replication factor ≥ 2）
- [ ] 数据写入失败有重试机制
- [ ] 预测结果写入失败有兜底（本地缓存+重试）

### 4.3 异常处理
- [ ] 天气预报API不可用时，预测服务不崩溃（有兜底）
- [ ] InfluxDB不可用时，预测服务仍能返回结果（内存缓存）
- [ ] Kafka不可用时，数据不丢失（本地缓冲）
- [ ] 求解器不可用时，MPC使用启发式兜底
- [ ] 模型加载失败时，自动回退到物理模型
- [ ] 全局异常处理已配置，不返回500裸错

## 五、安全检查

### 5.1 接口安全
- [ ] 生产环境API已配置鉴权（Token/API Key）
- [ ] 敏感接口（模型训练、模型切换）需管理员权限
- [ ] CORS已限制为具体域名
- [ ] 请求频率限制已配置（防DDoS）
- [ ] HTTPS已启用（生产环境）

### 5.2 数据安全
- [ ] 数据库访问已限制IP白名单
- [ ] 数据库密码已加密存储
- [ ] 敏感数据（如电价、结算数据）传输加密
- [ ] 日志中不打印敏感信息（密码、Token）
- [ ] 数据备份已加密

### 5.3 容器安全
- [ ] Docker镜像不以root用户运行
- [ ] 镜像已扫描漏洞（无高危漏洞）
- [ ] K8s Pod已配置SecurityContext
- [ ] 网络策略（NetworkPolicy）已配置
